# Menthor App 🌱🚀

**Menthor App** is a **decentralized application store** built on the **Velas Network (EVM compatible)**. It is designed to enable users to easily discover, publish, and interact with decentralized applications (**DApps**) in a secure and user-friendly environment.

---

## 🚀 What is Menthor App?

Menthor App is a Web3 platform that allows users and developers to:

- 🔍 **Explore** DApps built by the global community.
- 📤 **Publish** and distribute their own DApps in a decentralized and censorship-resistant store.
- 💳 **Pay fees** and perform on-platform actions using the native token **MENTA**.
- 🗳️ **Participate in governance** and community decisions through token-based voting.

---

## 🔧 Tech Stack

- **Velas Network (EVM-compatible)**
- **Solidity** (Smart Contracts)
- **React / Next.js** (Web frontend)
- **Flutter** (Mobile app frontend – Android & iOS)
- **Node.js / Express** (Backend API)
- **IPFS** (Decentralized file storage)
- **Hardhat** (Smart contract deployment and testing)
- **GitHub Actions** (CI/CD)

---

## 🧠 Project Philosophy

Menthor App aims to become the go-to DApp store for the decentralized world. Our mission is to promote open innovation, global accessibility, and user freedom through blockchain-based infrastructure.
